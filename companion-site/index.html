Assemble the kit

  1. Seat the e-paper FPC in the 24-pin connector, metal side up, and close the latch. The cable is fragile — never bend it sideways.
  2. Set the display jumper to 24Pin–GND.
  3. Connect the battery to the JST header (red = +, black = −).
  4. Plug the XIAO ESP32-S3 Plus into the driver board and connect USB-C.
  5. Press Connect over USB above. The terminal shows READY on the Build card within a few seconds.

Teach it a job

  1. Connect over USB above (or use the AP fallback in any browser).
  2. Enter your 2.4 GHz Wi-Fi and, optionally, an HTTPS content URL that returns the schema-1 card JSON.
  3. Save. The terminal caches the last good payload and keeps working without Wi-Fi.

Make it yours — the replacement-app recipe

The factory app is deliberately replaceable. Raw USB flashing is unrestricted: erase and flash your own firmware any time.

  1. Install Arduino CLI 1.5.1.
  2. Install the pinned core and libraries: 
    arduino-cli core install esp32:esp32@3.3.8 \
  --additional-urls https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
arduino-cli lib install "ArduinoJson@7.4.3"
# Seeed_GFX V3.1.0 ships as a GitHub ZIP:
#   https://github.com/Seeed-Studio/Seeed_GFX/archive/refs/tags/V3.1.0.zip
  3. Create a sketch with a driver.h: 
    #define BOARD_SCREEN_COMBO 502          // 7.5" UC8179 800x480
#define USE_XIAO_EPAPER_DISPLAY_BOARD_EE04
  4. Draw with EPaper (Seeed_GFX): epaper.begin(), draw, epaper.update(). Buttons are D1/D2/D4 (active-low), battery ADC on GPIO1 with the GPIO6 divider enable and 0.968 calibration.
  5. Ask Codex to build your app: "Write an Arduino sketch for the XIAO ESP32-S3 Plus with Seeed_GFX that fetches my build status every 15 minutes and renders it on the 800×480 e-paper, deep-sleeping between refreshes."
  6. Compile and flash over USB: 
    arduino-cli compile -b esp32:esp32:XIAO_ESP32S3_Plus MyApp
arduino-cli upload  -b esp32:esp32:XIAO_ESP32S3_Plus -p PORT MyApp

Bricked it? Hold the XIAO's BOOT button while plugging in USB and reflash — the USB bootloader always recovers the device.
